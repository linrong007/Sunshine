# AGENTS.md（Sunshine）

本文件面向在本仓库工作的 AI 编程助手。

## 工作方式

- 先读 `.sunshine/spec/` 与 `.sunshine/workflow.md`，再动手。
- 任务按 `.sunshine/tasks/` 里的拆分一轮一任务推进。
- 交付物写 `doc/`（需求、设计、原型、技术方案）；生产代码写 `src/`。

## 铁律

- 不口头改代码：需求变更先回源到 `.sunshine/` 与 `doc/`，再动手。
- 只改受影响的部分，未受影响的代码与样式不动。
- 子代理的活不代干：实现、检查、审查、调研都按 workflow 的派发协议走子代理，主会话只派发、收落盘汇报、把关；主会话直接做只限 workflow 写明的情形（如轻量档子任务）或用户明确要求，且要在汇报里说明依据，模型不得自批例外。
- 原型只出自子代理：`doc/prototype/` 下的文件只能由 sunshine-prototype 子代理产出，主会话只读不写；需要原型时先派发、收到落盘汇报才算数（小修例外见 workflow，且只限用户明确要求主会话直接改时）。
- 关键按钮必须加防抖或提交 Loading 状态。
